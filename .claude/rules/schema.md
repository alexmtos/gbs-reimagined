# Single sources of truth

- `schema/` holds the sources: register database, baseline programs, settings, API contract,
  translations. Everything derived from them is generated by `tools/codegen/generate.py` and
  committed; CI runs `generate.py --check` and fails on stale output.
- After editing anything in `schema/` or `tools/codegen/`, run `uv run tools/codegen/generate.py`
  and then the firmware host tests and the web tests.
- `schema/registers/tv5725.yaml` and `schema/programs/*.yaml` are factual chip data with recorded
  provenance (NOTICE.md). Change a value only with evidence: a datasheet page or a bench result,
  cited in the commit message.
- Register access (`ro`/`rw`) comes from the vendor document. Never mark a register in
  S0_00..S0_2F writable: the chip discards those writes silently.
